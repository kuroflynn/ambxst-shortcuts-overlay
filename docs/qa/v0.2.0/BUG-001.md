# BUG-001 — Sobrecierre de la sesión QA por input manual del usuario

Estado: **CERRADO — INVALID / FALSE POSITIVE.**
Fecha de detección: 2026-09-16. Cierre: 2026-09-16. Reporte de sesión: `docs/qa/v0.2.0/REPORT.md`.

## 1. Síntoma original registrado

Durante la sesión QA, con el overlay `kuroflynn.shortcuts-overlay` 0.2.0 activo, se registraron cierres del overlay y eventos `Escape` en las trazas de la generación instrumentada que se interpretaron como entradas espontáneas dentro de los ~2–4 s posteriores a cada apertura.

## 2. Causa confirmada

**QA contaminado por input manual concurrente del usuario.** El usuario estaba usando el equipo durante la ejecución del QA y cerró manualmente el overlay con `Escape` en varias ocasiones al verlo aparecer. Esos eventos (`wtype`/teclado real) fueron registrados por la instrumentación como pulsaciones reales y erróneamente atribuidos a un comportamiento espontáneo del overlay. El rango temporal observado (~2,3–4,6 s) y los paquetes de pulsaciones continuas son consistentes con la interacción humana concurrente, no con un defecto del artefacto.

## 3. Reclasificación

- Se descarta la hipótesis de cierre espontáneo del overlay.
- Se descartan las correcciones propuestas (debounce de `Escape`, cambios al manejo de `Escape`/`Shortcut`, investigación de entrega de teclas en Hyprland/wlroots) — **no proceden**.
- No se abre ningún caso derivado de este incidente.
- El overlay no presenta defecto de input; el comportamiento de toggle y `Esc` cumple los criterios QA.

## 4. Notas de contexto histórico (no interpretar como causa activa)

- La instrumentación registró eventos `Escape` reales llegando al shell de Quickshell; ello es coherente con input físico del usuario (no existe inyección en el código del proyecto ni demonios de teclado en el entorno).
- Las limitaciones del harness (sin inyección de click/rueda, dispatcher CLI de Hyprland en proveedor lua roto, logs de `qs` a `/dev/null`) quedan solo como notas informativas en el reporte; no determinan el cierre de este caso.
